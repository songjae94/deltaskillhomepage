# 홈페이지 디자인 기준

2026-11-27 사용자 요청: 다른 코드 수정 작업에서 디자인을 임의 변경하지 않는다.
현재 기준은 로컬 검토본이다. 심미적 최종 승인 또는 운영 배포 완료를 의미하지 않는다.

보호 대상: 디자인 CSS, 인증 CSS, 프린트 양식 선택/조판, 목재 이미지, 교재 표지 렌더 함수, 기본 프린트 설정.
`npm run check:design`은 파일 해시와 지정 소스 구간을 비교한다. 다른 파일에 새 CSS를 추가하는 우회 변경이나 모든 시각 회귀까지 자동 판별하지는 않는다.
후속 작업자는 AGENTS.md와 이 기준을 읽고 기능 수정을 수행한다. 사용자가 요청한 디자인 변경은 허용되지만 요청과 실렌더 검수 결과를 남긴 후 기준을 갱신한다.

기준 스크린샷은 이 채팅 outputs/기본_FOCUS4_유형편_1440.png 및 책장_상단_1440.png. 문항 예시는 기존 공개 자체 문항이며 연계교재 원문이라고 표시하지 않는다.
